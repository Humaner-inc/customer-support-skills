# Retail -- Payment Problems

## When to use

The customer reports a failed payment, unexpected charge, promo code that does not work, double charge, or wants to dispute a charge.

## Procedure

### 1. Identify the payment issue

- **Failed payment:** Transaction was declined or did not go through.
- **Unexpected charge:** Customer sees a charge they do not recognize or did not expect.
- **Promo code not working:** Discount code is rejected at checkout or not applied.
- **Double charge:** Customer was charged twice for the same order.
- **Charge dispute / chargeback:** Customer is disputing a charge with their bank.

### 2. Gather details

Get the order number (if one exists), the last four digits of the payment method, and the date of the charge. Pull up the order or transaction record from the knowledge base.

### 3. Investigate based on issue type

**Failed payment:**
- Check if the knowledge base shows a reason (insufficient funds, expired card, fraud block, unsupported payment method).
- Suggest the customer verify their card details, expiration date, and billing address.
- If the issue persists, suggest trying a different payment method.
- Do not access or ask for full card numbers.

**Unexpected charge:**
- Look up the charge in the knowledge base. Match it to an order, subscription renewal, or pre-authorization hold.
- Explain what the charge is for in plain language.
- If it is a pre-authorization hold, explain that it will drop off automatically (share the timeline from the knowledge base).
- If the charge is genuinely incorrect, escalate for a refund.

**Promo code not working:**
- Check the knowledge base for the promo code's terms: valid dates, minimum order, eligible products, one-time use, new customers only, etc.
- Explain why it may not be applying based on those terms.
- Do not create or invent promo codes. Do not override the system.

**Double charge:**
- Check the knowledge base for duplicate transactions on the same order.
- If one is a pre-authorization and the other is the actual charge, explain the difference and when the hold will release.
- If it is a genuine double charge, escalate for a refund of the duplicate.

**Charge dispute / chargeback:**
- This is an escalation trigger. Do not attempt to resolve chargebacks directly.
- Gather the details and escalate immediately to the appropriate team per the knowledge base.

### 4. Resolve or escalate

Apply the resolution from the knowledge base (adjust charge, issue refund, apply valid promo). If the issue requires billing team access or manager approval, escalate with full context.

## What not to do

- Do not ask for full credit card numbers, CVVs, or passwords.
- Do not invent prices, discounts, or promo code terms.
- Do not promise a refund amount or timeline not in the knowledge base.
- Do not attempt to resolve chargebacks; always escalate.
