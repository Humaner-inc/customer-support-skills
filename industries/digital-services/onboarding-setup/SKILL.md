# Digital Services -- Onboarding and Setup

## When to use

The customer is new and needs help getting started, is setting up their workspace or account, configuring integrations, importing data, or inviting team members.

## Procedure

### 1. Understand where the customer is

Ask what they have already done and what they are trying to accomplish. Common starting points:

- Just signed up, not sure where to begin.
- Account created, needs to configure settings.
- Needs to connect integrations (SSO, API, third-party tools).
- Needs to import existing data.
- Needs to invite team members and set permissions.

### 2. Guide through the setup sequence

Follow the onboarding steps from the knowledge base. Typical sequence:

1. **Account configuration:** Organization name, timezone, branding, defaults.
2. **User management:** Invite team members, assign roles and permissions.
3. **Integration setup:** Connect identity providers, APIs, third-party tools.
4. **Data import:** Migrate existing data from previous tools.
5. **Product walkthrough:** Key features relevant to the customer's use case.

Adapt the sequence to what the customer actually needs. Skip steps they have already completed.

### 3. Handle integration setup

Integrations are where most onboarding friction happens:

- Check the knowledge base for supported integrations and setup guides.
- Walk the customer through the specific integration steps.
- If the integration requires API keys or credentials from a third party, explain what is needed and where to find it. Do not store or ask for third-party passwords.
- If the integration fails, gather error details and check the knowledge base for known issues.

### 4. Handle data import

- Check the knowledge base for supported import formats and methods.
- Share file format requirements, size limits, and any data mapping instructions.
- If the import fails, ask for the error message and check the knowledge base.
- For large or complex migrations, check if the knowledge base offers migration assistance or professional services.

### 5. Confirm and provide resources

Once setup is complete, confirm the customer has what they need. Share:

- Links to documentation, help center, or getting-started guides from the knowledge base.
- How to reach support if they have more questions.
- Any scheduled onboarding calls or training sessions if the knowledge base offers them.

## What not to do

- Do not rush through setup steps. New customers need patience.
- Do not invent integration capabilities or supported formats.
- Do not store or ask for third-party credentials.
- Do not skip permission/role setup. It is important for security and usability.
